## Known discrepancy

`CLAUDE.md` documents `esp-tourbillon.yaml` + `esp-tourbillon/` as the one package-based exception in this repo, but neither exists at the repo root currently — two package-based configs exist instead: `_powmr-inverter-/` (lighter, undocumented convention: flat `modules/`, no NOTES.md/INDEX.md) and `esp32-monitor/` (richer esp-tourbillon-style convention: domain `packages/<domain>/`, per-domain NOTES.md, generated `packages/INDEX.md` via the repo-root `./reindex` script). `CLAUDE.md` does not yet document either — not fixed here; flagging only, per explicit user request to defer that update.
